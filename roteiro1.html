01 / O QUE VOCÊ ESTÁ CONSTRUINDO

Uma calculadora que entende regras.

Enunciado do professor ↗

Esta etapa recebe uma expressão como texto e calcula seu significado. Ainda não gera código de máquina. O exercício começa com números naturais, soma, subtração e espaços, aceitando várias operações na mesma entrada.

ENTRADA VÁLIDA

Mais de um dígito. Mais de uma conta.

11 + 22 - 3  →  30
100 - 1 - 1  →  98
0 - 5        →  -5

Os números escritos na entrada são naturais. O resultado pode ser negativo. Operadores de mesma precedência são aplicados da esquerda para a direita.

ENTRADA INVÁLIDA

Uma peça certa no lugar errado.

1 1   → falta um operador
+1    → falta o primeiro número
1+    → falta o próximo número

Um sinal antes do primeiro número ainda não é permitido. Multiplicação, divisão e parênteses também ficam fora desta etapa.

O enunciado exige o comportamento do programa, mas não impõe estas funções ou classes. Este guia usa a solução didática dos seus arquivos locais: funções independentes e uma lista de tokens. Lexer, Parser e Token como classes ficam para o roteiro 2.

Experimente:

01

Caractere

Uma posição da string. O texto 123 ocupa três posições. Um cursor percorre essas posições, incluindo os espaços.

02

Token

Uma peça reconhecida. Os três dígitos consecutivos viram uma única tupla: ("INT", 123).

03

Expressão

Uma sequência que obedece à regra: primeiro um número, depois zero ou mais pares operador + número.

Por que não apagar todos os espaços primeiro?

Em 12 + 3, os espaços podem ser pulados. Em 1 1, eles separam números diferentes. Se você fizer replace(" ", ""), esconderá esse erro ao transformar a entrada em 11. Percorrer a string preserva essa fronteira.

Por que split() sozinho não resolve a gramática?

Separar por um operador não trata automaticamente o outro, os números ausentes nem os espaços entre números. É possível construir uma solução com separações e validações extras, mas o cursor torna explícito o que foi lido e em que ordem.

03 / CADA FUNÇÃO TEM UM PAPEL

O vocabulário do roteiro 1.

As quatro primeiras funções formam a implementação enxuta. Os demais verbetes explicam os auxiliares dos materiais locais; não fazem parte da entrega mínima exigida pelo professor.

Variáveis, tuplas e índices: o que cada nome significa
codigo / caractere
Texto de entrada e caractere consultado na posição atual.
tokens
Lista de tuplas. Cada tupla contém tipo e valor, como ("INT", 22).
tokens[posicao][0]
Tipo do token naquela posição: INT, PLUS, MINUS ou EOF.
tokens[posicao][1]
Valor do token: um inteiro, o símbolo do operador ou a string vazia de EOF.
posicao
Em tokenizar(), conta caracteres. Em avaliar(), conta tokens. São variáveis locais distintas, mesmo que tenham o mesmo nome.
numero / DIGITOS
Texto que acumula os dígitos do número em leitura e conjunto de caracteres aceitos como dígitos.
resultado / operador
Conta parcial e operação guardada até que o próximo inteiro seja validado.
EOF
Token ("EOF", "") que marca o fim. Permite rejeitar operandos ausentes e detectar tokens sobrando.
append() / isspace() / int()
Recursos do Python usados para acrescentar um item à lista, reconhecer espaços e converter dígitos em número. Não são funções criadas pelo compilador.
sys.argv / print()
Argumentos recebidos do terminal e impressão na saída padrão. Use aspas para passar a expressão inteira como um só argumento.

Como essas funções se conectam

main()recebe a entrada e imprime
→
executar(codigo)coordena as duas fases
→
tokenizar(codigo)constrói a lista inteira
→
avaliar(tokens)confere a ordem e calcula

executar() espera tokenizar() terminar antes de chamar avaliar(). O resultado volta para main(). Se qualquer fase lançar uma exceção, esse fluxo é interrompido.

04 / A REGRA EM UM DESENHO

Um número. Depois, quantas operações couberem.

Ilustração criada para este guia a partir da gramática dos materiais locais. O enunciado oficial do roteiro 1 não apresenta uma imagem própria; este desenho não é atribuído ao professor como figura desse roteiro.

EXPRESSION = NUMBER, { ("+" | "-"), NUMBER } ;

As chaves indicam repetição: o trecho dentro delas pode ocorrer zero ou mais vezes. No código, essa repetição vira um while. O diagrama usa INT para representar o token numérico.

LEITURA INTERATIVA · EXPRSiga as setas. O retorno exige um novo inteiro.

Percorra o caminho com 11 + 22 - 3

Leia INT(11), volte por PLUS, leia INT(22), volte por MINUS, leia INT(3) e saia. A função avaliar() ainda precisa confirmar que o token restante é EOF.
